Dialogues (traduction) → Zoom Afficher :

Métatuiles

Clic = choisir · glisser = choisir un bloc (tampon). Clic droit sur la carte = pipette. « Copier zone » : glisse un rectangle sur la carte pour le recopier ailleurs.

Collision / altitude

Les tuiles peintes reçoivent la collision et l'altitude ci-dessus. Outil « Collision » : peint uniquement les bits de collision/altitude ci-dessus, sans changer le dessin.

Sélection

Choisis l'outil « Sélection » et clique un événement, ou un outil de création puis clique la carte.
